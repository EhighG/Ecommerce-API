# 구현 상태 정리

기준:
- 완료 항목은 별도 기록하지 않음
- 아래 목록은 현재 코드 기준의 남은 작업만 정리함
- 범위가 큰 작업부터 작은 작업 순으로 정렬함
- 채팅/채팅방은 현재 범위 제외 상태이므로, 아래 남은 작업에는 포함하지 않음

## 필수 준수 사항
- 각 작업들을 시작한다고 할 때, 로직 및 구현 관련 세부사항 중 불분명한 것들은, 모두 질문하여 구체화한다.
  - 질문은, 목록 형태로 모아서 제시한다.
- 코드 수정은 하지 않는다. 구현 코드와 로직 설명, 기반 개념을 답변으로 알려주기만 한다.

## 현재 남은 작업

1. 배송완료 주문항목 자동 구매확정 처리
배송완료일부터 4일 뒤 00:00까지 구매확정되지 않은 주문항목을 자동 구매확정하는 배치/스케줄 정책을 정리하고 구현한다.

2. 기본 썸네일 이미지 처리
상품 이미지가 없을 때 기본이미지를 내려주는 정책은 추후 정리한다.

3. 주문 상세 응답 필드 정리
주문 상세 응답에 구매자 정보와 상품 단가를 포함할지 정책을 정리한다.

4. GCS signing key 추가를 위한 ImpersonatedCredentials 기반 설정 및 환경변수 추가
