# 구현 상태 정리

기준:
- 완료 항목은 별도 기록하지 않음
- 아래 목록은 현재 코드 기준의 남은 작업만 정리함
- 범위가 큰 작업부터 작은 작업 순으로 정렬함
- 채팅/채팅방은 현재 범위 제외 상태이므로, 아래 남은 작업에는 포함하지 않음

## 필수 준수 사항
- 각 작업들을 시작한다고 할 때, 로직 및 구현 관련 세부사항 중 불분명한 것들은, 모두 질문하여 구체화한다.
  - 질문은, 목록 형태로 모아서 제시한다.
- 코드 수정은 하지 않는다. 구현 코드와 로직 설명, 기반 개념을 답변으로 알려주기만 한다.
