# 요구사항 정의

> 프론트 측 없이, 서버 단 엔드포인트(rest api)까지를 최종 결과물로 함.
>
> 채팅/채팅방(chat/chatRoom)은 원래 서비스 요구사항에 있었으나, 현재는 범위에서 제외한다.
> 아래 채팅 관련 내용은 이후 재활성화를 위해 비활성화 상태로 남겨둔다.

## Updates
### 26.04.17
Payment쪽은 구현 복잡도 증가로 일단 범위에서 제외.


- 유저는 구매자 or 판매자일 수 있다. (관리자는 일단 불필요?)
- 판매자는 상품을 등록할 수 있다
- 판매자는 자기 상품의 정보와, 실시간 재고정보를 확인할 수 있다
  - 목록/상세 페이지로 구성
  - 재고정보는 목록페이지에서도 수정 가능
- 판매자는 자기 상품을 수정/삭제할 수 있다
  - 수정 가능 필드:
    - 재고
    - 단가
    - 설명
    - 이미지
    - 썸네일 이미지
- 상품 정보는 아래와 같이 구성 (화면에 보이는 정보 기준)
  - 상품명
  - 이미지(0~n개)
  - 썸네일 이미지(이미지 없을 시 기본이미지)
  - 가격
  - 실시간 남은재고
  - 카테고리
  - 판매자
  - 리뷰 평점 평균
- 판매자는 자기 상품에 대한 주문 건을 주문취소/배송중/배송완료 처리할 수 있다
  - 주문취소는 '주문완료' 상태인 주문만 가능하다.
- 구매자는 여러 상품을 장바구니에 담고, 한번에 주문할 수 있다.
- 주문 건의 가능한 상태값은 아래와 같음
  - 주문완료 -> 배송중 -> 배송완료 -> 구매확정 / 주문취소
  - 여러 상품을 한번에 주문했을 때, 주문상태는 전체 주문 1개가 아닌, 각 상품별로 존재.
- 배송완료일부터 4일 뒤 00:00까지 구매확정 안 된 주문건은, 자동 구매확정됨
- 유저는 상품 목록을 조회 / 단일상품을 상세조회할 수 있다.
- 유저는 상품명 키워드, 판매자 ID, 카테고리 ID로 상품 목록을 조회할 수 있다.
- 유저는 주문 많은 순/별점 높은 순/조회순/가격 낮은 순으로 상품 목록을 정렬해서 조회할 수 있다.
  - 주문 많은 순은 주문취소 상태의 주문항목을 제외하고 집계한다.
- 상품 목록조회 시, 페이징은 항상 적용되고, 페이지 사이즈는 20(기본값)/50/100으로 조절 가능하다.
- 구매자는 재고수량 >= 주문수량인 상품을 주문할 수 있다.
- 구매자는 '주문완료' 상태인 자신의 주문항목은 취소할 수 있다.
- 구매자는 배송완료 상태인 자신의 주문을 구매확정 처리할 수 있다.
- 구매자는 자신의 구매확정된 주문 건이 있는 상품에, 상품당 1개의 리뷰를 남길 수 있다.
- 유저는 상품 상세페이지를 통해, 해당 상품에 대한 리뷰를 목록조회할 수 있다.(최신순 only)
- 리뷰 작성자는 자신이 작성한 리뷰를 수정할 수 있다. 삭제는 할 수 없다.
- 리뷰는 아래와 같이 구성(화면에 보이는 정보 기준)
  - 작성자 nickname(삭제한 유저는 별도 표시)
  - 최종수정일(수정한적 없으면, 등록일)
  - 평점(0~5, 0.5 단위)
  - 내용
- 유저 정보는 아래와 같이 구성(화면에 보이는 정보 기준)
  - 이메일
  - 닉네임
  - 가입일
  - 작성한 리뷰 목록
    - 총 개수
    - List of
      - 상품정보
        - 상품명
        - 썸네일 이미지
      - 리뷰정보
        - 평점
        - 최종수정일(수정한적 없으면, 등록일)
        - 내용
- 주문 정보는 아래와 같이 구성
  - 주문 헤더
    - 주문번호(=주문 엔티티 ID)
    - 구매자
    - 총 주문금액
    - 주문일시
  - List of
    - 주문항목
      - 상품정보
        - 상품명
        - 판매자
        - 단가
        - 썸네일 이미지
      - 주문수량
      - 주문금액
      - 주문상태
      - 배송완료일시

## 비활성화된 채팅 요구사항

- [비활성화] 구매자는 특정 상품에 대해, 해당 상품 판매자와 1:1 채팅을 통해 문의 등을 할 수 있다.(명시적으로 buyer + product unique조건을 두진 않음. 추후 필요시, 한쪽만 남고 오래된 채팅 삭제 batch작업 추가)
  - [비활성화] 대신 '채팅 시작하기' 등 요청 시, 상대방과의 활성화된(둘 다 참여중인)채팅 있는지 체크 후, 있으면 그 채팅 표시
- [비활성화] 판매자는 특정 상품에 대해 구매자가 채팅방을 연 경우, 해당 채팅방에서 채팅을 전송할 수 있다.
- [비활성화] 판매자가 다른 유저에게 먼저 1:1채팅을 보낼 수는 없다.
- [비활성화] 유저는 두 참여자 다 참여중인 채팅방에서, 채팅 전송/자기 채팅 수정/자기 채팅 삭제를 할 수 있다.
- [비활성화] 채팅은 최신순 목록조회 및 페이징된다.(일반적인 채팅방 UI처럼 위로 무한스크롤 처리)
- [비활성화] 유저는 채팅방을 나갈 수 있다.
- [비활성화] 상대방이 나간 채팅방은, 내용 읽기 및 나가기만 가능하다. 채팅 전송/수정/삭제는 불가능하다.
- [비활성화] 양쪽 유저가 나간 채팅방은 DB에서 삭제된다.
- [비활성화] 유저는 채팅방 목록 페이지를 통해, 자신이 나가지 않은 채팅방을 조회할 수 있다. 채팅방 목록은 최신순 조회, 페이징된다.
- [비활성화] 채팅방 목록 화면에서, 채팅방 정보는 아래와 같이 구성
  - 상대방 정보
    - 닉네임
  - 마지막 채팅 정보
    - 내용
    - 등록일시
  - 읽지 않은 채팅 개수(lastReadChatId 기반 계산)
- [비활성화] 채팅방 안 화면에서 필요한 정보들은, 아래와 같이 구성
  - 상대방 정보
    - 닉네임
    - 가입일
  - 채팅 목록
    - 최신순 List of
      - 내용
      - 수정여부
      - 등록일시
- [비활성화] 채팅 정보는 아래와 같이 구성
  - 작성자
  - 내용
  - 등록일시
  - 수정일시
  - 상대방 읽음 여부
    => 채팅방에 참여자(seller/buyer)별 lastReadChatId를 두는 방식으로 구현
  - 전송자가 삭제한 채팅은 '삭제된 메시지입니다' 로 표시

## 삭제 정책

- 사용자: soft
- 상품: soft
- [비활성화] 채팅방: hard
- [비활성화] 채팅: 작성자가 삭제 시 soft, 종속 채팅방 삭제 시 hard
- 리뷰: 삭제불가
- 주문: 주문 헤더단위 삭제 없음. 주문 항목단위 상태값 변경(취소처리)만 있음

## Update/Delete Propagation

- 구매자
  **Update**
  - to 리뷰
    - 항상 최신정보
  - to 주문
    - 항상 최신정보
    > 구매자 정보 중 배송지 정보가 있었다면, update아닌 capture 방식으로 해야했을 것. 그러나 이 서비스에서는 해당 정보 없음.
    >
    > **Delete**
  - to 리뷰
    - 전파 X (=삭제된 유저의 리뷰로 표시)
  - [비활성화] to 채팅방
    - 해당 유저 나감처리
  - [비활성화] to 채팅
    - 전파 X
  - to 주문
    - 전파 X
- 판매자
  **Update**
  - [비활성화] to 채팅방, 채팅
    - 항상 최신정보
  - to 상품
    - 항상 최신정보
  - to 주문 - 전파 X. (주문 당시의 판매자정보 유지)
    **Delete**
  - [비활성화] to 채팅방
    - 해당 유저 나감처리
  - [비활성화] to 채팅
    - 전파 X
  - to 상품
    - 전파 O (상품 삭제정책에 정의한 대로 삭제처리)
  - to 주문
    - 전파 X
    - 주문완료 or 배송중 상태인 주문이 있으면, 판매자 삭제 불가
- 상품
  **Update**
  - to 주문 - 전파 X (= 주문건에서는, 주문 당시의 상품정보 유지)
    **Delete**
  - to 장바구니
    - 전파 O (= 해당 상품이 담긴 장바구니 품목 hard delete)
  - to 주문
    - 전파 X(= 주문건에서는, 주문 당시의 상품정보 유지)
  - to 리뷰
    - 전파 X (= 삭제된 상품의 리뷰로 유지)
- [비활성화] 채팅방
  **Update**
  - to 채팅 - 항상 최신정보 유지
    **Delete**
  - to 채팅
    - 채팅방 삭제 시 채팅도 삭제
