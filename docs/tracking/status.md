## 남은 작업 (우선순위 순)

1. **기존 문서 전면 개편**: `README.md`, `docs/api-spec.md`, `docs/project-requirements.md`, `docs/assets/`의 다이어그램. 모두 현재 코드와 어긋난다(오류 코드 타입과 메시지, 로그인 실패 상태 코드, 삭제된 상품 수정 시 상태 코드, 세션 쿠키 이름 등).
2. **장바구니 테스트 보강 마무리**: 현재 브랜치 작업.
3. **오류 응답 결함 수정**
   - 쿼리 파라미터 조건 위반이 500으로 나가는 문제
   - 본문 교차 검증 오류가 `"요청 Body 읽기 실패"`로 뭉개지는 문제
   - 쿼리 enum 오류에 영문 프레임워크 메시지가 노출되는 문제
4. **빠진 기능**
   - 상품 상세에서 바로 주문(장바구니를 거치지 않는 주문 생성)
   - 자동 구매확정(배송완료 서울 날짜 + 4일의 00:00까지 확정하지 않은 주문항목. 예: 9/1 15:00 배송완료 → 9/5 00:00). 여러 인스턴스에서 동시에 돌아도 안전해야 한다
   - 상품이 걸린 카테고리 삭제 거절(400 또는 409, 전용 오류 코드)
   - 할인액 0원 쿠폰 적용 거절(쿠폰 전용 오류 코드와 사유 메시지)
5. **테스트가 없는 영역에 테스트 추가**: 인증·인가 매트릭스, 상품·검색, 쿠폰 발급, 리뷰, 사용자 탈퇴.
